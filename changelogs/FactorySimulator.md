FactorySimulator 1.1.1 更新内容
================================

本版本围绕“工厂经营 RPG 化”补充了工人、设备成长、成就和排行榜系统，并完善了生产线运行、离线收益、配置与 PlaceholderAPI 展示能力。

新增
----
- 新增工人系统：玩家可以使用 `/fs workers hire` 雇佣工人，使用 `/fs workers fire` 解雇工人，使用 `/fs workers info` 查看当前工人数、上限和雇佣费用。
- 新增工人配置：支持配置最大工人数、雇佣价格和解雇返还比例。
- 新增设备升级系统：使用 `/fs machine upgrade` 升级准星指向的自有设备。
- 新增设备等级数据：设备等级会写入工厂资料，支持配置最大设备等级和不同设备的升级费用。
- 新增地皮升级成长：地皮升级会同步提升工厂等级，并按照当前地皮规模计算升级费用。
- 新增成就系统：自动记录首台设备、工业园、资金里程碑、团队建设、最大地皮和工厂大亨等成就。
- 新增成就开关：可以在 `factory.yml` 中开启或关闭成就判定。
- 新增排行榜：支持按工厂资金或工厂等级查看排行榜，命令为 `/fs top` 和 `/fs top level`。
- 新增排行榜配置：支持配置排行榜开关和显示条数。
- 新增 PlaceholderAPI 变量：新增资金排名、等级排名、成就数量和离线收益变量。
- 新增生产设备：补充煤炭、铁矿、黄金、红石、钻石采矿机，以及工业熔炼机、自动装配机、电力熔炉、燃料发电机等设备配置。
- 新增生产物品标识：生产产物使用隐藏标识，便于在容器和流水线之间识别与同步。
- 新增工厂专属世界保护：限制玩家只能在自己的工厂地皮内放置、拆除和操作设备，并阻止破坏墙壁、地板等保护方块。
- 新增机器容器同步：设备内部库存会与工厂世界中的容器状态同步，重启或重新加载后能够恢复生产线物品。
- 新增工厂教程书和设备商店入口，帮助新玩家完成创建工厂、购买设备和搭建生产线的入门流程。

更改
----
- 工厂资料模型扩展为支持工人数量、设备数量、设备等级、设备库存、成就、离线收益和排行榜所需数据。
- 生产系统改为按配置的 tick 间隔扫描生产线，采矿机生产产物，加工设备转换材料，自动售货机自动出售产物。
- 离线收益根据玩家离线时间、生产设备数量、生产周期和配置倍率结算，并在玩家上线时计入工厂资金。
- 工厂等级、地皮规模、设备解锁等级和设备购买价格统一从 `factory.yml` 读取，支持服务器按需要调整成长曲线。
- `/fs buy <设备ID> [数量]` 支持一次购买 1-2304 个设备，并校验设备解锁等级、资金和背包空间。
- 教程书商店支持点击设备后在聊天框输入数量购买，输入 `cancel` 可以取消购买。
- `/fs machine give` 支持管理员指定在线玩家和数量发放设备，同时保留给管理员自己发放的兼容格式。
- 工厂信息查询增加等级、地皮、资金、工人、设备、离线时间和成就数量等统计信息。
- 服务器状态信息增加存储类型、PlaceholderAPI、Vault 和全息功能状态展示。
- PlaceholderAPI 扩展标识继续使用 `factorysimulator`，并保持已有变量兼容。
- YAML、SQLite、MySQL 三种存储继续使用统一的 `FactoryStorage` 接口，工厂资料可按配置持久化。
- 工厂世界和 YAML 玩家资料继续存放在插件目录的 `world/`、`data/` 子目录，不散落在服务端根目录。
- 所有新增简体中文消息统一使用 `messages.yml` 选择语言，并支持 `{prefix}` 统一前缀替换。

新增命令
--------
- `/fs workers info`：查看工人信息。
- `/fs workers hire`：雇佣一名工人。
- `/fs workers fire`：解雇一名工人并按配置返还费用。
- `/fs machine upgrade`：升级准星指向的自有设备。
- `/fs top`：查看资金排行榜。
- `/fs top level`：查看工厂等级排行榜。

新增 PlaceholderAPI 变量
------------------------
- `%factorysimulator_rank%`：按资金排序的当前玩家名次。
- `%factorysimulator_rank_money%`：按资金排序的当前玩家名次。
- `%factorysimulator_rank_level%`：按工厂等级排序的当前玩家名次。
- `%factorysimulator_achievements%`：当前玩家已获得的成就数量。
- `%factorysimulator_achievement_count%`：`achievements` 的别名。
- `%factorysimulator_offline_money%`：当前记录的离线收益金额。

配置变化
--------
- `factory.yml` 新增工人配置、设备升级配置、成就配置、排行榜配置和更多设备/产物价格配置。
- 支持配置最大工人数、雇佣费用、解雇返还比例、设备最大等级和设备升级费用。
- 支持配置排行榜是否启用以及排行榜显示数量。
- `lang/zh_cn.yml` 新增工人、设备升级、排行榜、成就和状态提示消息。
- 修改存储类型、数据库连接、世界生成或软依赖开关时仍建议完整重启服务器。

修复与稳定性
------------
- 修复 PlaceholderAPI 扩展中资金排名变量分支重复导致的逻辑问题。
- 修复地皮升级后工厂等级未同步增加的问题。
- 修复设备容器库存与工厂资料不同步时可能造成生产线状态丢失的问题。
- 修复批量购买输入非法数量时的边界校验问题。
- 修复管理员发放设备命令权限和目标玩家参数校验不统一的问题。
- 保持存储初始化异步执行，避免在异步初始化阶段直接操作 Bukkit 生命周期。

兼容性
------
- Minecraft/Paper：1.12.2。
- Java：8 或当前 Paper 服务端支持的 Java 版本。
- PlaceholderAPI、Vault、HolographicDisplays、Multiverse-Core 均按软依赖处理，未安装时核心工厂功能仍可启动。
- 旧版本已有的 YAML、SQLite/MySQL 工厂资料格式和基础命令保持兼容；升级前仍建议备份 `plugins/FactorySimulator/`。
