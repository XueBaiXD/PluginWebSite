# 欢迎来到 XueBaiXD 的插件小屋

## 关于这里

这是一个个人插件发布页。

我平时会写一些 Minecraft 服务端插件，主要都是给自己和朋友的服务器用的，写着写着感觉还不错，就整理出来放这儿了。

这里不是商业网站，也不是什么大团队。就是一个人，一台服务器，一台电脑，慢慢做东西。更新随缘，有问题随时反馈，能改就改。

## 使用规则

说是规则，其实也就几条，都是常识。

### 1. 可以做的

- 下载插件，在自己服务器上用
- 修改配置文件，改到符合自己需求
- 在自己的群里、论坛上分享这个网站
- 反馈 bug、提建议、提需求
- 参考插件的实现思路写自己的插件

### 2. 不可以做的

- **反编译、破解、去除版权信息后重新分发**
- **声称插件是你自己写的**
- **把插件放到任何付费资源站或搬运站**
- **在插件里插入后门、挖矿代码等恶意功能后转发**
- **倒卖**：拿我的插件当自己作品卖给别人

简单的判断标准：**自己用没问题，传播要注明出处，卖钱不行。**

### 3. 关于二次修改

如果你改了插件自己用，随便改。

如果你改完想发布，需要：

1. 事先跟我说一声
2. 在描述里写明基于我的插件修改
3. 保留原作者信息

不是要卡你，只是不想让别人误以为是原版。

## 反馈渠道

| 渠道 | 用途 |
|---|---|
| QQ 群 | 日常答疑、聊天 |
| 邮箱 | 正式反馈、合作咨询 |
| GitHub Issues | 明确的 bug 报告和功能建议 |

具体联系方式见 **运营团队** 页面。

反馈时请尽量说清楚：

- 你用的是哪个插件，什么版本
- 服务端类型和版本（Paper / Spigot / 版本号）
- 报错信息（完整贴出来，不要只发一张图）
- 复现步骤（做什么操作出现的）

信息越全，解决越快。只说"插件坏了"，我很难帮你。

## 关于插件本身

### 免费还是收费

目前所有插件都是**免费**的。

将来如果出了比较复杂的功能，可能会考虑收一点费用，但已有的免费插件不会变成收费。

### 更新频率

不定。有时候一周更三次，有时候一个月不动。看什么时候有灵感，或者有人报 bug。

### 支持的服务端

主要是 **Paper**，其他分支（Spigot、Purpur）大部分也能跑，但不保证。

版本一般跟最新的稳定版走，老版本不一定兼容。

### 出问题了怎么办

按这个顺序：

1. 看插件详情页的**常见问题**章节，八成有答案
2. 看**插件效果**里的截图，确认你的配置是不是和示例一致
3. 都排除了，再联系我

先自己查一遍，能省很多来回。
